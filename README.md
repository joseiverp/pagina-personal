# Jose Peñarrieta · Página personal

Sitio web personal estático desarrollado con HTML, CSS y JavaScript sin frameworks.

- **URL de publicación:** https://joseiverp.github.io/pagina-personal/

## Cómo ejecutar

### 1. Instalación de dependencias
Para instalar las herramientas de desarrollo y validación requeridas:
```bash
npm install
```

### 2. Ejecución de los tests
Para verificar el cumplimiento de los estándares HTML y ejecutar la suite completa de pruebas unitarias:
```bash
npm test
```

### 3. Inicio del servidor local
Para levantar un servidor local en el puerto 8080 que sirva el contenido de la carpeta `site/`:
```bash
npm start
```
Una vez iniciado, abre tu navegador en `http://localhost:8080`.
